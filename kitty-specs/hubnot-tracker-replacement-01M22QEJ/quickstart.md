# Planned operator flow

This interface is pending implementation/qualification; final current instructions live in docs/HUBNOT_TRACKER.md.

1. Install exact qualified Hubnot via scripts/install-qualified-hubnot.sh; retain source/build/digest receipt.
2. Explicitly select existing Hubnot workspace/public actor and create versioned binding with canonical project/workspace/executable/tuple. Beads bindings are not converted automatically.
3. Run spec-kitty tracker inspect --binding /absolute/path/binding.json without control-root initialization.
4. Use inventory for complete current definitions, define to create rich work, definition to read it, and documented catalog/graph/assignment/discussion commands.
5. Reuse original portable operation ID on retry. Resolve conflicts/ambiguity explicitly; changing the key is not recovery.

Guarded definition updates, atomic assignment and conditional compensation remain unsupported. Tracker operations do not adopt a release or authorize mission execution. Qualification uses disposable repositories; real binding selection is a separate explicit operator action.
